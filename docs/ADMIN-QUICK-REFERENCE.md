## Daily Event Checklist

### Morning Before Event
- [ ] Set event status to **"In Progress"**
- [ ] Enable **"Scoring Open"** toggle
- [ ] Print tee sheet (2 copies)
- [ ] Verify all RSVPs confirmed
- [ ] Test member login access

### After Event
- [ ] Disable **"Scoring Open"**
- [ ] Verify all scores entered
- [ ] Review results for accuracy
- [ ] Click **"Finalize Event"** (applies deductions)
- [ ] Publish results
- [ ] Send results communication
- [ ] Record prize payments

## Quick Actions

### Add New Member
1. **Settings → Members**
2. Add Member
3. Enter: Name, Handicap, PIN
4. Save

### Create Event
1. **Event Management → Create New Event**
2. Enter: Name, Date, Fee
3. **Course Settings:** Select course, H/C %
4. **Load Scorecard from Master**
5. Save

### Manage RSVPs
- **Add:** Event → Add RSVP → Select member
- **Remove:** Event → RSVPs → Remove (🗑️)
- **Payment:** Click Society/Club/Unpaid buttons

### Setup Tee Times
1. **Event → Tee Times**
2. Enter: First tee, Interval, Groups
3. **Generate Tee Times**
4. **Drag-drop members** into groups

### Enter Scores
1. **Admin → Scoring**
2. Find member → Edit
3. Enter gross scores
4. Save (auto-calculates points)

### Finalize Results
1. **Disable Scoring**
2. **Event → Finalize Event**
3. Review winners
4. **Publish Results**

## Emergency Fixes

| Problem | Solution |
|---------|----------|
| Member can't login | Members → Edit → Reset PIN |
| Scores not saving | Check "Scoring Open" is ON |
| Wrong handicap | Check Index & Deductions |
| Leaderboard frozen | Refresh page (F5) |
| Can't load scorecard | Settings → Verify scorecard exists |
| Tee time wrong | Drag member to correct group |

## Key Numbers

- 1st Place: **-3 shots**
- 2nd/3rd: **-2 shots**
- Front 9: **-1 shot**
- Back 9: **-1 shot**
