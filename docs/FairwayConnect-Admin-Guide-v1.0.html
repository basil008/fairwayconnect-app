1. Getting Started

This guide covers everything you need to manage your golf society through the FairwayConnect admin dashboard. From creating events to publishing results, this manual will walk you through each step.

Accessing the Admin Dashboard

To access the admin area:

1. Open your browser and go to fairwayconnect.fly.dev/admin

2. Enter the admin PIN: 2026

3. You'll be taken to the admin dashboard

⚠️ Important

Keep the admin PIN secure. Only share it with authorised administrators. The PIN provides full access to create events, enter scores, and publish results.

Admin Dashboard Overview

The admin dashboard is your central hub. From here you can:

Feature Description
Create & manage events Set up outings with course details, dates, and tee times
Manage players Add players to events, track RSVPs
Enter scores Input hole-by-hole scores during or after an outing
Publish results Finalise events, generate prizes, and update standings
Manage deductions View and edit the deductions sheet
Update handicaps Keep member handicap indexes current

2. Managing Events

Events are the core of FairwayConnect. Each outing is set up as an event with course details, date, and tee time configuration.

2.1 Creating a New Event

To create a new event:

1. From the admin dashboard, click 'Create Event' or the '+' button

2. Enter the event details:
• Event name (e.g., 'Spring Outing - Portmarnock')
• Date of the outing
• Course name

3. Configure the tee settings (see Section 2.2)

4. Save the event — it will appear on the calendar immediately

2.2 WHS Course Settings

For accurate handicap calculations, you need to set up the course details according to the World Handicap System (WHS).

Setting Description
Slope Rating The slope rating of the course from the selected tees (e.g., 128)
Course Rating (CR) The course rating for the selected tees (e.g., 72.1)
Par The par for the course (e.g., 72)
Tees Select which tees will be played (e.g., White, Yellow, Red)

2.3 Handicap Allowance

FairwayConnect uses a 95% handicap allowance as standard, in line with Golf Ireland recommendations for individual Stableford competitions.

📝 Note

The 95% allowance is applied automatically when calculating playing handicaps. You don't need to adjust this manually — the system handles it based on each player's handicap index and the course settings.

3. Players & RSVPs

3.1 Adding Players to Events

To add players to an event:

1. Open the event from the admin dashboard

2. Go to the Players tab

3. Click 'Add Player' and select from the member list

4. The player will be added with a default RSVP status

3.2 Managing RSVPs

Each player's RSVP status can be set to one of three states:

Status Meaning
✅ Confirmed Player has confirmed they will attend
❓ Maybe Player hasn't decided yet
❌ Declined Player has declined the invitation

You can easily see who hasn't responded yet — players without a confirmed or declined status will be highlighted.

3.3 Tee Time Management

To set up tee times:

1. Go to the Tee Times section of the event

2. Set the first tee time and interval between groups (e.g., 10 minutes)

3. Drag and drop players into groups

4. Arrange the order within each group as needed

5. Click 'Recalculate Times' if you change the interval or first tee time

💡 Tip

Use the drag-and-drop feature to quickly rearrange players between groups. The 'Recalculate Times' button will automatically update all tee times based on the interval you've set.

4. Entering Scores

Score entry is done through the Scorecards tab on each event. Scores are entered as gross (actual shots taken) and the system automatically calculates Stableford points.

4.1 Using the Scorecards Tab

To enter scores for a player:

1. Open the event and go to the Scorecards tab

2. Select the player from the list

3. Enter the gross score for each hole (1-18)

4. Stableford points are calculated automatically based on the player's playing handicap

5. The leaderboard updates in real time as scores are saved

4.2 Stableford Auto-Calculation

The system automatically calculates Stableford points using the following formula:

Score vs Par (net) Stableford Points
2+ under par (Eagle or better) 4 points
1 under par (Birdie) 3 points
Par 2 points
1 over par (Bogey) 1 point
2 over par (Double bogey) 0 points
3+ over par 0 points
No score / Pick up 0 points

4.3 Handicap Deductions & Scoring

The playing handicap is calculated from each player's handicap index using the WHS formula with the course's slope rating, course rating, and par. The 95% allowance is applied automatically.

Handicap strokes are distributed across holes based on the stroke index. The system handles all of this automatically — you just enter the gross scores.

⚠️ Important

Always enter GROSS scores (actual shots taken). Do not subtract handicap strokes — the system does this automatically when calculating Stableford points.

5. Side Competitions

Side competitions add extra fun and prizes to each outing. FairwayConnect supports several types of side comps.

5.1 Types of Side Competitions

Competition Description
Nearest the Pin (NTP) Closest tee shot to the pin on a par 3. Measured from the pin.
Longest Drive Longest drive on a designated hole. Must be on the fairway.
Twos Club Any player who scores a 2 on any hole (gross score).

5.2 Adding Side Competition Entries

To add a side competition result:

1. Open the event and go to the Side Competitions section

2. Select the competition type (NTP, Longest Drive, or Twos)

3. Select the player and the relevant hole number

4. Add any additional details (e.g., distance for NTP)

5. Save the entry

5.3 Editing or Deleting Entries

You can edit or delete any side competition entry at any time before the event is finalised. Simply click on the entry to edit, or use the delete button to remove it.

6. Publishing Results

Publishing results is the final step after all scores have been entered. This process generates prizes, applies deductions, and updates the GOTY standings.

6.1 Recalculate Scores

Before publishing, use the 'Recalculate Scores' button to:

  • Refresh all Stableford calculations based on current handicaps

  • Update rankings to reflect any score corrections

  • Verify that all calculations are correct before finalising

⚠️ Important

Always click 'Recalculate Scores' before finalising, especially if you've made any changes to scores or handicaps after initial entry.

6.2 Finalise & Publish

When you click 'Finalise & Publish', the system performs several actions automatically:

Action What Happens
Generate Prizes Determines 1st, 2nd, 3rd place winners, plus Front 9 and Back 9 winners
Apply Deductions Applies each player's deductions to their Stableford score to determine final rankings for prizes
Auto-Write Deductions Automatically calculates and writes new deductions for the next event based on this event's results
Update GOTY Updates the Golfer of the Year standings with this event's Stableford scores

6.3 Revert to In Progress

If you need to make changes after publishing, you can use 'Revert to In Progress'. This will:

  • Change the event status back to 'In Progress'

  • Remove the generated prizes

  • Reverse the deductions that were auto-written for the next event

  • Remove this event's contribution to the GOTY standings

  • Allow you to edit scores, add/remove players, and re-publish

📝 Note

Use 'Revert to In Progress' carefully. It's designed for corrections — for example, if you discover a scoring error after publishing. Always re-publish after making your changes.

7. Deductions Management

The deductions system is a society-specific handicapping mechanism that ensures consistent winners don't dominate every event. Understanding how it works is crucial for accurate results.

7.1 How Deductions Work

Each player carries a deductions total that accumulates throughout the season. This total is composed of:

  • Year starting deductions — carried over or reset at the start of each season

  • Per-outing adjustments — added or subtracted based on results

7.2 Deduction Values

Result Deduction Change
1st Place -3 (three shots deducted)
2nd Place -2 (two shots deducted)
3rd Place -2 (two shots deducted)
Front 9 / Back 9 Winner -1 (one shot deducted)
Played but didn't win +1 (one shot earned back)

7.3 Where Deductions Apply

Competition Deductions Applied?
Overall Prize (1st/2nd/3rd) ✅ Yes — deductions affect the final ranking
Front 9 / Back 9 Prizes ❌ No — these are based on raw Stableford points
GOTY (Golfer of the Year) ❌ No — GOTY uses pure Stableford scores

7.4 Viewing and Editing the Deductions Sheet

To view or edit deductions:

1. Open the event from the admin dashboard

2. Go to the Deductions tab

3. You'll see each player's deduction total

4. To edit: click on a player's deduction value and enter the corrected amount

5. Changes are saved automatically

⚠️ Important

Manual edits to deductions should be rare. The system automatically manages deductions when you Finalise & Publish an event. Only edit manually if correcting an error.

8. Member Management

Member management is handled through the admin handicaps page. This is where you keep handicap indexes up to date for all society members.

8.1 Accessing Member Management

To manage members:

1. Go to fairwayconnect.fly.dev/admin/handicaps

2. You'll see a list of all registered members with their current handicap indexes

8.2 Updating Handicap Indexes

To update a player's handicap index:

1. Find the player in the list

2. Click on their handicap index value

3. Enter the new handicap index

4. Save the change

📝 Note

When you update a player's handicap index, the system automatically recalculates their playing handicap for any upcoming events they're registered for. This ensures scores are always based on the most current handicap.

⚠️ Important

Check handicap indexes regularly against the official Golf Ireland handicap system to ensure accuracy. Players' indexes can change after any qualifying round.

9. Printing

FairwayConnect provides print-ready formats for key documents you may need on the day of an outing.

9.1 Print Scorecards

To print scorecards for an event:

1. Open the event from the admin dashboard

2. Click the 'Print Scorecards' button

3. The system generates formatted scorecards for all confirmed players

4. Each scorecard includes: player name, playing handicap, hole details, and stroke index

5. Use your browser's print function (Ctrl+P / Cmd+P) to print

9.2 Deductions PDF

To generate a printable deductions sheet:

1. Go to the Deductions section

2. Click the 'Print' or 'Export PDF' option

3. The deductions sheet will be formatted for A4 printing

4. This is useful for displaying at the society event or distributing to members

💡 Tip

Print scorecards and the deductions sheet before each outing so players can see their current deductions on the day.
